## 🛠️ Technology Stack (Target)
- **Backend:** Java Spring Boot / Maven
- **Frontend:** Responsive Web Interface (HTML5, Vanilla CSS, JS/Thymeleaf)
- **Database:** H2 Database (In-Memory for simple DevOps flow)
- **CI/CD:** Jenkins (Pipeline as Code via `Jenkinsfile`)
- **Testing:** Selenium WebDriver
- **Containerization:** Docker
- **Configuration & Provisioning:** Ansible / Puppet

---

## 📂 Directory Structure
- `docs/` - Requirements, architecture diagrams, weekly logs, and user documentation.
- `src/` - Application source code (to be initialized in Week 3/4).
- `ci/` - Jenkins pipeline scripts, Dockerfiles, and configuration files.
- `tests/` - Selenium WebDriver test suites.
- `provisioning/` - Ansible playbooks / Puppet manifests.
